# Specification 00: Build & Configuration System

## 1. Overview & Objective
This specification defines the build system, package manifest, directory structure, compiler settings, and build output isolation for `http_logviewer`.
The primary requirement is that **all build files, intermediate caches, and final binaries must reside strictly inside the `build/` directory**.

---

## 2. Directory Layout Specification
The repository must conform to the following directory layout:

```
http-logviewer/
├── http_logviewer.nimble     # Nimble package manifest
├── nim.cfg                   # Root compiler configuration
├── build/                    # Isolated build outputs (never committed)
│   ├── http_logviewer        # Compiled CLI binary
│   └── nimcache/             # Intermediate C/object files generated by Nim
├── src/
│   ├── http_logviewer.nim    # Main CLI entry point and library export
│   └── http_logviewer/       # Internal modules
│       ├── core/
│       ├── parser/
│       ├── enrichment/
│       ├── analyzer/
│       ├── renderer/
│       └── cli/
├── tests/
│   ├── config.nims           # Test configuration
│   └── fixtures/             # Real-world log test fixtures
└── specs/                    # Implementation specifications
```

---

## 3. Package Manifest (`http_logviewer.nimble`)
The package manifest must configure `binDir = "build"` and provide utility tasks for developer ergonomics:

```nim
# Package
version       = "0.1.0"
author        = "titanomachy"
description   = "High-performance HTTP log viewer and rogue bot detector"
license       = "MIT"
srcDir        = "src"
binDir        = "build"
installExt    = @["nim"]
bin           = @["http_logviewer"]

# Dependencies
requires "nim >= 2.2.10"

# Tasks
task release, "Build optimized release binary":
  exec "nim c -d:release --opt:speed --outdir:build src/http_logviewer.nim"

task debug, "Build debug binary with line tracking":
  exec "nim c -d:debug --outdir:build src/http_logviewer.nim"

task clean, "Clean all build artifacts":
  rmDir "build/nimcache"
  rmFile "build/http_logviewer"
```

---

## 4. Root Compiler Configuration (`nim.cfg`)
To guarantee that direct invocations of the Nim compiler (e.g., `nim c src/http_logviewer.nim`) do not pollute the workspace root with a `nimcache/` folder or output binaries in the root, create `nim.cfg` in the project root:

```cfg
# Route compiler cache and output files into build/
--nimcache:"build/nimcache"
--outdir:"build"

# Modern ARC/ORC deterministic memory management
--mm:orc

# Enable hints and safety warnings
--warning[ProveField]:on
--styleCheck:hint
```

---

## 5. Verification & Acceptance Criteria
1. Executing `nimble build` completes with exit code 0.
2. The compiled binary is located at `build/http_logviewer`.
3. All intermediate C files (`*.c`, `*.o`, `*.json`) are located inside `build/nimcache/`.
4. No compiler cache or binary files appear in the project root or `src/`.
5. Executing `./build/http_logviewer` runs the executable properly.
